# OfferLab

An interactive five-year compensation calculator for comparing job offers and understanding negotiation levers.

## Features

- Configurable company, role, and currency
- Base salary growth and target bonus calculations
- Custom stock vesting schedules
- Sign-on payments, refresh equity, and other cash by year
- Four- and five-year compensation summaries
- Target-gap and compensation-cliff analysis

OfferLab runs entirely in the browser. No compensation data is uploaded or stored.
